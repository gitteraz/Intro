# Intro React App

This project is now a standard React application powered by Vite.

## Requirements

- Node.js 18+
- npm 9+

## Install

```bash
npm install
```

## Develop locally

```bash
npm run dev
```

The Vite dev server will print the local development URL in the terminal.

## Build for production

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```
